🧠 Explanation of each
Package	Purpose
pyspark	Core library for running Spark transformations
google-cloud-storage	Connects to GCS to read/write files
google-cloud-bigquery	Loads or queries data in BigQuery
pandas / numpy	Optional — used for local data validation or debugging
pyarrow	Enables efficient Parquet read/write support
protobuf	Required for some GCP SDKs (dependency compatibility)
